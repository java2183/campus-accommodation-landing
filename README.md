# CampusNest

CampusNest is a student accommodation management system concept created by **Innovation Tech** for the Software Engineering Foundations assignment.

## The problem

Students currently have to apply for accommodation in person through a manual process. Paper-based applications, room allocation, payment records, and updates are difficult for students to follow and for accommodation staff to coordinate.

## The proposed system

CampusNest proposes one organised digital workflow for students and accommodation staff. The landing page introduces:

- Online accommodation applications
- Application status updates
- Room allocation management
- Payment record tracking
- An organised staff overview
- Clearer student support and communication

This repository contains the project landing page, not a live accommodation management service. The application, allocation, and payment features are presented as the proposed system; they are not implemented as working backend services here.

## Run locally

This is a static HTML, CSS, and JavaScript website with no build step or package installation.

1. Open `index.html` in a browser, or start a local static server from the project directory:

   ```sh
   python -m http.server 8000
   ```

2. Visit [http://localhost:8000](http://localhost:8000).

The page uses local images from `image/`. Google Fonts are loaded from Google Fonts when an internet connection is available; system font fallbacks are defined.
